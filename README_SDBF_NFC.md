本项目完全遵循[原项目的协议](https://github.com/Yorunina/No-Flesh-Within-Chest-2/blob/main/LICENSE)。

本项目为整合包《千界万锻》的非官方拓展包。
当前移植了魔法体系以外的脆骨症II器官系统，并确保了每种胸腔都有对应的生物。
任务拥有非常基础的引导，只负责引导玩家升级胸腔，对于其他的大多数扩展内容则暂时不负责。
本拓展包的性质偏整活。
本拓展包会导致原整合包的数值体系崩溃。
本拓展包不对任何平衡性问题负责，因为项目本身存在过多的难以平衡的设计。
由于原整合包和本拓展包中都未包含机械动力与血肉模组，相关的配方和流程可能会被大幅简化或移除。
尽情的享受吧！

请使用SDBF_DLC_Installer-0.1.0.jar安装器安装本拓展包：
1. 将SDBF_DLC_Installer-0.1.0.jaf复制到版本文件夹下（与kubejs文件夹同级）
2. 打开SDBF_DLC_Installer-0.1.0.jar，或者使用控制台手动选择兼容版本的java打开
3. 选择本扩展包的压缩文件，然后选择安装
4. 记得备份存档！本拓展包对原存档是毁灭性的，请提前做好备份！
